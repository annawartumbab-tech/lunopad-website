Política de Privacidade

Informações sobre o tratamento de dados no aplicativo Luna Pad para Android.

Última atualização: 18 de novembro de 2026

1. Identificação do aplicativo e contato

Esta Política de Privacidade se aplica ao aplicativo Luna Pad, identificado no Google Play pelo nome de pacote com.lunapad.topgame. Para dúvidas relacionadas à privacidade, entre em contato pelo e-mail support@lunapadgame.com.

2. Dados coletados e acessados

O aplicativo não coleta dados pessoais ou dados sensíveis dos usuários. Não coletamos informações como nome, e-mail, número de telefone, localização, contatos, identificadores do dispositivo ou dados de uso por meio do aplicativo.

3. Uso e compartilhamento de dados

Como não coletamos dados pessoais por meio do aplicativo, não usamos esses dados para publicidade, análise de comportamento, criação de perfis ou outras finalidades. O aplicativo não transmite nem compartilha dados pessoais dos usuários com terceiros.

4. Armazenamento, retenção e exclusão

O aplicativo não mantém uma base de dados pessoais de usuários. Portanto, não há dados pessoais coletados pelo aplicativo para reter ou excluir em nossos sistemas. Se você entrar em contato por e-mail, as informações enviadas voluntariamente nessa comunicação serão utilizadas apenas para responder à sua solicitação e poderão ser excluídas mediante pedido ao endereço de contato acima, respeitadas eventuais obrigações legais.

5. Segurança

Como o aplicativo não coleta nem transmite dados pessoais, não há transferência de dados pessoais do aplicativo para nossos servidores a proteger. Adotaremos medidas adequadas de proteção caso as práticas de tratamento de dados sejam alteradas no futuro.

6. Serviços de terceiros

Segundo as práticas de privacidade declaradas para o aplicativo, não há compartilhamento de dados pessoais com terceiros, incluindo para fins de publicidade e análise. Caso sejam incorporados serviços que realizem coleta ou compartilhamento de dados, esta política será atualizada para informar essas práticas.

7. Privacidade de crianças

O aplicativo não coleta intencionalmente dados pessoais de crianças ou de outros usuários. Esta política de não coleta se aplica a todos os usuários do aplicativo.

8. Alterações desta política

Esta Política de Privacidade poderá ser atualizada se houver mudanças no aplicativo, nos serviços utilizados ou em exigências legais. A versão vigente será publicada nesta página, com a respectiva data de atualização.

9. Dúvidas e solicitações

Se você tiver perguntas sobre esta Política de Privacidade ou desejar fazer uma solicitação relacionada a dados pessoais, escreva para support@lunapadgame.com.

Escopo: esta política descreve as práticas de dados do aplicativo Android Luna Pad. O funcionamento técnico da hospedagem deste site é independente do aplicativo.
